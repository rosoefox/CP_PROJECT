# CP_PROJECT

초급프로젝트 Term Project — React + Firebase 웹서비스 (JCloud 배포)

## 기술 스택
- React + Vite
- Firebase Authentication / Cloud Firestore
- Vitest (테스트)
- GitHub Actions (빌드·테스트 CI)

## 요구 사항
- Node.js 20 이상

## 설치 및 실행
```bash
npm install      # 의존성 설치
npm run dev      # 로컬 개발 서버 실행
npm run build    # 프로덕션 빌드 (dist/)
npm run preview  # 빌드 결과 미리보기
```
